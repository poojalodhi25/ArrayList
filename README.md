# 📚 ArrayList in Java

Welcome! 👋

This repository is all about **Java ArrayList**.

## 🤔 What is ArrayList?
Unlike arrays, you don't need to specify the size beforehand.

ArrayList is a class in the java Collation framework
ArrayList is a dynamic array in Java meaning it size increase or decrease automatically.

LinkedList
Dynamic size.
Stores elements as connected nodes.
Faster insertion and deletion than ArrayList in many cases, but slower random access


Package:

```java
import java.util.ArrayList;
```
# ⭐ Features

- Dynamic Size
- Stores Duplicate Elements
- Maintains Insertion Order
- Fast Random Access
- Easy to Add and Remove Elements

  
In simple words:

> Array: "Bas itni hi jagah hai." 😐

Kab kya use kare?
Array → Jab size pehle se fixed ho aur fast index access chahiye.
ArrayList → Jab size frequently change ho aur index se access zyada karna ho.
LinkedList → Jab elements ko baar-baar add/remove karna ho.
Easy Trick to Remember
📦 Array = Fixed Box (size change nahi hota)
📚 ArrayList = Expandable Bag (zarurat par bada ho jata hai)
🔗 LinkedList = Chain of Nodes (har node next node se connected hota hai)
